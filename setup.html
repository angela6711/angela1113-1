建立公開共用 Google Sheets 帳本

依擁有者選擇，這是公開共用模式：任何訪客都能查看、新增、修改與刪除帳目。網站不要求登入或金鑰。

  1. 帳本擁有者登入 Google，開啟 Google Apps Script，建立「新專案」，命名為「想飛記帳本」。
  2. 將 Code.gs 完整程式 複製到編輯器的 Code.gs，取代預設內容並儲存。專案設定 → 勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」，將 appsscript.json 完整內容貼上並儲存。
  3. 函式選擇 setup，按「執行」，依 Google 畫面授權讀寫試算表。若出現自建應用未驗證提示，請先確認程式內容與擁有者，再依畫面繼續。此步驟會建立新的「想飛記帳本」試算表；執行記錄會顯示連結。重複執行不會再建第二份。
  4. 「部署」→「新增部署作業」→ 類型「網頁應用程式」→「執行身分」選「我」→「誰可以存取」選「任何人」→ 部署。複製結尾為 /exec 的網址。若 Workspace 管理員禁止此選項，須先請管理員允許。
  5. 在 GitHub 儲存庫的 cloud-config.json，把 url 的空字串改成上一步的完整 /exec 網址並提交。這個網址是公開的，不是密碼。網站發布後，每位訪客開啟同一個網站網址，就會自動連到同一份帳本。若由開發者代填，只需提供部署網址，不需提供 Google 密碼。
  6. GitHub → Settings → Pages → Source 選擇 GitHub Actions，再從 Actions 執行「Test and publish PWA」。等待成功後開啟 Pages 提供的網址。請以工作流程結果確認網址已上線。
  7. 在 App 新增一筆測試收支，確認「已同步 Google Sheets」，並到試算表「交易明細」確認。用另一台手機開啟相同網站網址，確認能查看並修改同一筆資料。
前景約每 30 秒檢查其他裝置更新，本機修改後約 1 秒啟動同步；可以按「立即同步」。離線先存在裝置，關閉 App 後不保證背景同步，下次開啟會重試。兩台裝置同時修改會提示版本衝突，請先下載 JSON 備份，再選擇保留本機或雲端。Google 帳本資料經公開 API 開放讀寫，沒有使用者隔離或登入權限。

試算表包含「帳本資料」「交易明細」「固定支出」「月結報表」。請透過 App 修改帳目；明細分頁是檢視用，直接改儲存格不會回寫 App。試算表檔案本身可保持限制分享，不影響所有訪客透過網站讀寫。

iPhone：Safari 分享 → 加入主畫面。Android／電腦：瀏覽器「安裝應用程式」。須使用 HTTPS 或本機開發伺服器；直接點開 HTML 不支援 PWA。第一次開啟需要網路。
